## Chirucat 能做什么？

- **跨平台**：同一个机器人可以出现在多个聊天平台，无论用户在哪里聊天，机器人都能回应
- **多Bot**：想跑几个机器人就建几个，互不干扰，还能共用同一套功能
- **插件即功能**：机器人会什么，由插件决定。需要什么功能，就给机器人装上对应的插件
- **跨平台认识用户**：同一用户在不同平台会被识别为同一个人，方便实现跨平台的功能

## 快速开始

不需要会编程，跟着步骤做就行。

### 1. 安装 Node.js

到 [nodejs.org](https://nodejs.org) 下载并安装 LTS 版本。

### 2. 获取 Chirucat

获取项目代码（Git 克隆或 ZIP 解压），在项目文件夹里打开终端，执行：

```bash
npm install
```

### 3. 创建你的机器人

在 `bots/` 文件夹里新建一个文件夹（比如 `my-bot`），在里面创建 `config.json`：

```json
{
  "id": "my-bot",
  "name": "我的机器人"
}
```

- `id`：机器人的唯一标识（不能重复）
- `name`：机器人的名字

### 4. 给机器人装插件

插件是机器人功能的来源。把插件文件夹放进：

- `plugins/` —— 所有机器人共享
- `你的机器人目录/plugins/` —— 只有这个机器人用

然后在机器人的 `state.json` 里开启要用的插件：

```json
{
  "enable": true,
  "plugins": {
    "ping": true
  }
}
```

- `enable`：机器人是否启动
- `plugins`：每个插件的开关，`true` 开，`false` 关

### 5. 启动

在项目文件夹执行：

```bash
npm test
```

机器人就按配置跑起来了。

### 连接聊天平台

要让机器人上某个聊天平台，需要安装对应的「适配器」插件（由社区提供）。接入方法见对应插件的说明。

## 概念速览

| 名词 | 是什么 |
| --- | --- |
| 机器人（Bot） | 一个聊天机器人实例，有自己的名字和插件 |
| 插件 | 机器人的一项功能，装了就多一个本事 |
| 适配器 | 连接机器人和聊天平台的「桥梁」，每个平台一个 |
