# 插件开发准则

在为Chirucat开发插件时，请遵循以下准则，以确保插件的质量、可维护性和与框架的兼容性。

1. **永远不要尝试访问或修改框架对象中以`_`开头的属性或方法**: 这些属性更多为框架内部使用, 在框架中这些是受保护字段, 即便它们在js或 `as any`可被访问, 也不应被插件直接使用。

2. **为保证跨平台数据绑定, 建议使用`user.unionId`**: 如果你的插件不需要跨平台数据绑定, 也可以使用`user.id`作为用户唯一标识符, 但请注意, 这会导致无法跨平台绑定数据。

3. **插件应注意资源管理**: 在插件的`unload`方法中, 框架会尝试回收`ctx`对象上的副作用, 但无法干预其他资源，确保正确释放所有资源，如定时器、事件监听器和网络连接等，以避免内存泄漏和性能问题。

4. **插件应避免阻塞主线程**: 插件的`init`和`unload`方法, 以及注册的回调应尽量保持轻量和快速执行，避免长时间阻塞主线程，以确保框架的响应性和稳定性。

5. **插件应减少使用`ctx.message.all()`**: 非必须时应避免注册全量消息回调, 建议使用其他方法, 以避免插件再进行消息匹配

6. **插件应使用`ctx.logger`记录日志**: 使用logger对象以便于调试和问题排查, 避免直接使用`console.log`，以确保日志的一致性和可管理性。

7. **插件不应进行数据窃取, 或未经用户同意收集敏感信息**: 插件应尊重用户隐私和数据安全, 遵守相关法律法规, 并在必要时获取用户的明确同意。

---

良好地遵守这些准则将有助于提高插件的质量和用户体验，同时确保插件与Chirucat框架的兼容性和稳定性。
